# ND-014.4A — Single-Thevenin R-L waveform supplement

**Status:** Implemented as a supplementary engineering calculation.
**IEC status:** Not an IEC 60909-0:2026 Clause 10 implementation. The restricted estimate is carried in separate supplementary fields on the study result; the normative `iDC` and `Ibasym` statuses remain unavailable.
**Baseline:** ND-014.4, 461 Windows tests.

## Purpose

Provide an independently callable time-domain model for a balanced sinusoidal source behind one lumped Thevenin R-L impedance. The model calculates the aperiodic (DC) offset at first-pole contact separation and the corresponding asymmetrical RMS current under the constant-AC-component assumption.

The feature is deliberately separate from `IEC60909Calculator`. It must not be used as a substitute for IEC 60909 methods for multiple sources, rotating-machine decrement, converters, unbalanced sequence networks or meshed-network equivalent-frequency procedures.

## Model

For a single Thevenin impedance `Z_th = R + jX`, with `R >= 0`, `X > 0`, angular frequency `omega = 2*pi*f`, and symmetrical AC RMS current `I_sym`, the time constant is:

\[
\tau = \frac{L}{R} = \frac{X}{\omega R}
\]

For `R = 0`, the idealized model has no DC decay (`tau` is represented as unbounded and the decay factor is 1).

Let `phi = atan2(X, R)` be the impedance angle and `alpha` the source-voltage inception angle. The phase current is represented as:

\[
i(t)=\sqrt{2}I_{sym}\left[\sin(\omega t+\alpha-\phi)-\sin(\alpha-\phi)e^{-t/\tau}\right]
\]

For `R = 0`, the exponential term is interpreted as constant. At the selected contact-separation instant `t_s`, the signed DC component and asymmetrical RMS value are:

\[
i_{DC}(t_s)=-\sqrt{2}I_{sym}\sin(\alpha-\phi)e^{-t_s/\tau}
\]

\[
I_{asym,rms}(t_s)=\sqrt{I_{sym}^{2}+i_{DC}^{2}(t_s)}
\]

When `alpha` is omitted, the calculator selects the inception angle yielding the maximum initial DC offset. When the caller supplies `alpha`, the actual angle-specific offset is evaluated.

## Implementation

- `TheveninRLWaveformCalculator` validates all scalar inputs and the impedance quadrant.
- `RLShortCircuitWaveformResult` is immutable and includes the method identifier, signed DC offset, decay factor, time constant, asymmetrical RMS value, and an instantaneous-current evaluator.
- The package-level numerical infrastructure exports both types.
- Unit tests cover the analytical time constant, maximum-offset case, zero-offset inception angle, waveform initial condition, zero-resistance limit, and invalid inputs.

## Explicit limitations

This is a single-equivalent, single-time-constant physical model. The symmetrical AC component is held constant. It does not model:

- multiple source contributions with distinct R/L time constants;
- generator subtransient/transient AC decrement;
- induction motor or converter controls/current envelopes;
- unbalanced fault sequence coupling;
- meshed network equivalent-frequency correction;
- arcing, saturation, switching transients or breaker arc dynamics.

The output `asymmetrical_breaking_current_rms_ka` is a result of this engineering model only. When propagated by the IEC study facade, it is stored under `asymmetrical_breaking_current_ka` with a `PFA-ENGINEERING/...` method identifier. The normative `iDC` and `Ibasym` quantity keys remain unavailable, and this estimate must not be cited as an IEC 60909 Clause 10 result.
